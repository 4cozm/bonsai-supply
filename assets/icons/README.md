# EVE 타입 아이콘

이 폴더에 아이콘을 **미리 넣어두고** 정적으로 서빙한다. 런타임에 외부 이미지 서버를 때리지
않는 이유는 세 가지다.

1. GitHub Pages는 정적 호스팅이라 외부 요청이 그대로 사용자 브라우저에서 나간다 — 서드파티
   가용성과 레이트리밋에 화면이 묶인다.
2. 재고 표는 한 화면에 수십 개의 아이콘을 동시에 요청한다.
3. 아이콘은 거의 바뀌지 않는다. 매번 받아올 이유가 없다.

## 파일 규칙

```
assets/icons/types/{typeId}_64.png
```

`typeId`는 EVE의 `type_id`이고, [app.js](../js/app.js)의 `iconSrc()`가 이 경로를 만든다.
파일이 없으면 인라인 SVG 자리표시자로 조용히 대체되므로, 아이콘을 나중에 채워 넣어도 화면은
깨지지 않는다.

## 아직 정해야 할 것

목업 데이터의 `typeId`는 전부 `0`(자리표시자)이다. 실제 값은 ESI에서 받아온다:

- `GET /corporations/{id}/assets/` — 행어 보유 수량과 `type_id`
- `GET /universe/types/{type_id}/` — 이름, `volume`(m³)

아이콘 팩 자체는 아직 고르지 않았다. 정하고 나면 여기에 출처와 라이선스를 적어둘 것.
현재 재고 표에 필요한 것은 **64px 타입 아이콘**뿐이고, 함선 렌더는 쓰지 않는다.
